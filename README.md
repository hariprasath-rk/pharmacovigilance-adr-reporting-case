# Simulated Pharmacovigilance ADR Case Report

## Overview

This project demonstrates the preparation and documentation of a
Suspected Adverse Drug Reaction (ADR) case using the CDSCO/PvPI
Suspected ADR Reporting Form.

## Case Summary

- Patient: A.R.
- Age: 42 years
- Sex: Female
- Suspected Drug: Amoxicillin + Clavulanic Acid
- Indication: Acute bacterial sinusitis
- Adverse Reaction: Generalized erythematous skin rash, pruritus and mild facial swelling
- Reaction Onset: 22/08/2026
- Action Taken: Suspected medication withdrawn
- Outcome: Recovering
- Dechallenge: Positive
- Rechallenge: Not applicable
- Causality Assessment: Probable/Likely

## Skills Demonstrated

- ADR identification
- Suspected drug assessment
- ADR case documentation
- Seriousness assessment
- Dechallenge and rechallenge assessment
- Causality assessment
- ADR narrative writing
- Pharmacovigilance case processing

## Disclaimer

This is a fictional case created solely for educational and
pharmacovigilance internship training purposes. It does not
represent a real patient or actual ADR report.
